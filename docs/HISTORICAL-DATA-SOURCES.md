# Historical data sources

## Strongest verified candidate: OpenBible.info Bible Geocoding Data

The repository catalogs identifiable biblical places, possible ancient-to-modern identifications, Bible verse references, coordinates/geometry, confidence information, and source metadata. Its README states that the data is licensed CC BY 4.0. OpenStreetMap-derived data and images have separate licensing requirements and must not be treated as covered by CC BY 4.0 automatically.

### Offline use

Use the place/identification/source data for:

- biblical geography
- ancient place descriptions
- modern identification candidates
- coordinates and map data
- confidence/uncertainty indicators
- verse-to-place links
- source provenance

Do not import thumbnails or OSM-derived material until their separate licenses are verified.

## Historical/theological commentary

Historical Christian Faith Commentaries Database remains a candidate for verse-linked historical and theological commentary. Its underlying quotations must be individually checked for redistribution rights.

## Amharic layer

The geography records can be translated into Amharic descriptions in our own data layer where permitted. For copyrighted secondary historical material, use licensed text or create original Amharic summaries rather than copying protected prose.

Every Amharic explanation must retain source attribution and, where applicable, confidence/uncertainty information.
