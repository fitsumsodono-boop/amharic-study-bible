# Original-Language Lexical Explanation

This project must provide both **English lexical information** and a dedicated **Amharic explanation layer** for Greek and Hebrew words.

## Required display for a word

1. Original word (Greek/Hebrew)
2. Lemma
3. Transliteration
4. Pronunciation when available
5. Strong's number when available
6. Morphology and parsing
7. English lexical definitions from licensed sources
8. Amharic lexical explanation
9. Semantic range
10. Meaning in the specific verse/context
11. Related occurrences in Scripture
12. Relevant historical/theological notes
13. Church Father interpretation where available
14. Source and license attribution

## Important distinction

A lexical definition is not automatically the meaning of a word in every verse. The application must distinguish:

- lexical/semantic range;
- grammatical form;
- contextual sense;
- theological interpretation.

The Amharic explanation should preserve these distinctions and should not invent a single "true meaning" when the evidence supports multiple senses.

## AI separation

The Amharic lexical explanation is part of the **offline study-source layer** only when it is based on licensed, stored data. AI-generated explanations belong to a separate AI layer and must identify themselves as synthesis rather than canonical source material.
