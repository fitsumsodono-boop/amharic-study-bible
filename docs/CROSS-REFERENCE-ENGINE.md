# Cross-reference and thematic linking engine

The knowledge base uses typed links rather than a single undifferentiated list of references.

## Supported relationships

- parallel passages
- direct quotations
- allusions
- prophecy/fulfillment
- themes
- explanation
- contrast
- genealogy
- historical events
- geography
- word studies

## Confidence

Each relationship can be marked explicit, strong, probable, or possible. This prevents a possible allusion from being presented as a certain quotation.

## Multilingual explanation

Each link can contain an English reason and an Amharic reason. The Amharic field is for a permitted translation/editorial explanation and must retain the underlying source attribution.

## Knowledge-graph connections

A verse may link to:

`verse -> verse -> person -> place -> event -> historical context -> theology -> Church Father -> lexical entry`

The links remain source-aware and license-aware. AI may traverse and summarize the graph, but AI-generated claims are not inserted into the offline source records as if they were primary data.
