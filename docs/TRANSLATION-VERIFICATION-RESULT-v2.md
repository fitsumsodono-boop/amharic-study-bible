# EthiopicBibleAPI translation verification

The `beldados/EthiopicBibleAPI` Books dataset is confirmed to contain Amharic Bible text. Its Ephesians 1:1 wording matches the Amharic 1954 (`አማ54`) Ephesians 1:1 reference exactly in the available comparison source, while the New Amharic Standard Version uses materially different wording in comparable passages. This is strong evidence that the dataset is based on the older/1954 Amharic text.

This is not a legal redistribution determination. The upstream API repository may be MIT-licensed while the Bible text itself can have separate provenance/rights. The source is therefore tagged `am-1954-candidate` rather than being treated as unrestricted for redistribution.

Evidence: GitHub Books directory; direct Ephesians source inspection; አማ54 Ephesians 1:1 comparison; NASV comparison passages.

Import status: `am-1954-candidate` — edition identification: strong evidence; redistribution permission: pending verification.

Do not label the source as NASV/አዲሱ መደበኛ.
