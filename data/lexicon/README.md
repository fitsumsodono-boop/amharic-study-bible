# Greek/Hebrew lexical layer

This directory defines the normalized lexical layer for the study engine.

Every lexical entry should support:

- Original Greek/Hebrew lemma
- Transliteration and pronunciation where available
- Strong's identifiers where available
- English lexical definitions from licensed sources
- Amharic lexical explanation
- Semantic range
- Morphological information
- Syntax information where available
- Verse-specific sense
- Related words
- Source attribution

## Interpretation rule

The dictionary gloss is not automatically the meaning of a word in every verse. The app must distinguish lexical range from contextual sense and theological interpretation.

## Source rule

No third-party lexicon should be copied into the repository until its exact license and attribution requirements have been verified.
